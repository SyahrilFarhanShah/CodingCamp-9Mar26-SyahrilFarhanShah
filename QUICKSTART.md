# Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Option 1: Open Locally (Easiest)

1. Download or clone the repository
2. Open `index.html` in your web browser
3. Done! Start using the dashboard

### Option 2: Deploy to GitHub Pages (5 minutes)

1. Create a GitHub account (if you don't have one)
2. Fork this repository
3. Go to Settings → Pages
4. Select "Deploy from a branch" → "main" → "/"
5. Your site is live at `https://yourusername.github.io/productivity-dashboard`

## 📋 Using the Dashboard

### Greeting
- Shows current time and date
- Updates every second
- Time-appropriate greeting

### Timer
- Click **Start** to begin 25-minute timer
- Click **Stop** to pause
- Click **Reset** to return to 25:00
- Timer continues even if you close the tab

### To-Do List
- Type task and press Enter to add
- Click **Edit** to modify task
- Click checkbox to mark complete
- Click **Delete** to remove task

### Quick Links
- Enter link name and URL
- Click **Add** to save
- Click link to open in new tab
- Click **Delete** to remove link

## 💾 Your Data

All data is saved automatically:
- Tasks are saved when you add/edit/delete
- Links are saved when you add/delete
- Timer state is saved every second
- Data persists across browser sessions

## 🆘 Troubleshooting

### Data not saving?
- Check if Local Storage is enabled in browser
- Try opening in incognito/private window
- Check browser console for errors (F12)

### Timer not working?
- Refresh the page
- Check if JavaScript is enabled
- Try a different browser

### Links not opening?
- Make sure URL starts with `http://` or `https://`
- Check if pop-ups are blocked
