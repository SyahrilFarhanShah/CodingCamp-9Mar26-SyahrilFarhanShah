## 🚀 Deploy in 3 Steps

### Step 1: Push to GitHub
```bash
git add .
git commit -m "Initial commit: Productivity Dashboard"
git remote add origin https://github.com/yourusername/productivity-dashboard.git
git branch -M main
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to Settings → Pages
2. Select "Deploy from a branch" → "main" → "/"
3. Click Save

### Step 3: Done!
Your site is live at: `https://yourusername.github.io/productivity-dashboard`
